# Тестовое задание ТОЛЬКООПТ

Python 3.10+, только стандартная библиотека. Устанавливать зависимости не нужно.

- `starter.py` — исправленный расчёт цены; интерфейс `recommend_price` сохранён.
- `test_starter.py` — два автоматических теста: обычный расчёт с фильтрацией и округлением вниз; тайм-аут источника с сохранением текущей цены.

## Запуск тестов

Из корня репозитория:

```sh
python3 -m unittest -v test_starter.py
```

## Запуск примера

```sh
python3 starter.py
```

Ожидаемый результат: `price = Decimal('4728.00')`, `decision = 'APPLY'`.
